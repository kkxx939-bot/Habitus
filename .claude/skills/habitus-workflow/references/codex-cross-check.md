# 跨模型复核（codex）

## 为什么用另一个模型

让同一个模型扮演不同角色，它的盲点不会变：一个人设漏掉的，另一个人设大概率也会漏掉。codex 报的结论同样要回源码核，写出 `file:line`。换一个模型，盲点才真正不同。所以第二视角交给 codex，而不是再派一个 Claude 子代理。

## 给它什么

- **只给**：共享说明、文件范围、检查问题清单。
- **不给**：Claude 这边任何审核者的报告、主会话的判断、疑似问题列表。给了它，它就会去确认这些结论，而不是独立找问题。

## 命令

只读运行，结果写到文件：

```bash
codex exec \
  -m gpt-5.6-terra \
  -s read-only \
  -C /Users/gulf/PycharmProjects/Habitus \
  -o <scratch>/workflow/<日期>-<范围>/codex-report.md \
  - < <scratch>/workflow/<日期>-<范围>/codex-prompt.md
```

- 模型用 `gpt-5.6-terra`（中档、均衡；用户 2026-11-02 定：太弱的模型看不出效果），**不开 fast**。`~/.codex/config.toml` 里的默认 `gpt-6.1-sol` 在当前 ChatGPT 账号下报 `model_not_found`，所以必须显式写 `-m`。codex 用不了时见下一节，不等。
- `-s read-only`：保证它不改任何文件。

## codex 用不了的时候：立刻换，不卡住

依据用户 2026-11-03 的口径："codex 额度不够了就切换……等 codex 额度恢复之后再用 codex，我的意思不要卡住"。这条取代了之前"等额度重置"的写法。

**怎么判定用不了**：codex 进程非 0 退出，并且报的是额度、认证、模型不可用（`model_not_found`）这类错误；或者连续两次超时。模型答得差、格式不对，不算用不了，那是复核质量问题，照常处理。

**换成什么**：本机 Claude Code CLI，**显式指定模型**（不写就会落到 CLI 默认的 opus，又贵又和主会话同一档）。模型和跑数回退保持一致，用 sonnet 4.5（用户 11-03 定）。只读：不给它任何写文件的工具。

```bash
claude -p \
  --model claude-sonnet-4-5 \
  --disallowedTools Edit Write NotebookEdit \
  --output-format text \
  < <scratch>/workflow/<日期>-<条目>/codex-prompt.md \
  > <scratch>/workflow/<日期>-<条目>/fallback-review.md
```

- 在仓库根目录下运行；`codex-prompt.md` **原样给它**，同样不附 Claude 这边任何结论。
- 2026-11-04 实测：这条命令跑的确实是 `claude-sonnet-4-5`，Write 被拒、文件没有落地。但 Bash 仍然开着（它要用 grep、git diff），理论上能用命令写文件；所以跑之前、跑之后各看一次 `git status --short`，有任何变化就作废这份报告并告诉用户。
- 报告开头写明：`复核模型：claude-sonnet-4-5（codex <报错原文>，<时刻>）`。

**独立性打了折扣，要补上**：替补和主会话都是 Claude 家族，盲点可能有重叠，所以：
1. 不卡流程：第 4 步用替补的结果照常往下走。
2. **到阶段边界之前，codex 恢复了**：用 codex 对这一阶段里触及主流程的改动补做一次复核，只看和之前结论不一致的地方；不一致的照常进入独立复现。
3. **到阶段边界 codex 还没恢复**：在给用户的汇报里写明"本阶段跨模型复核由 sonnet 4.5 代替，codex 未补做"，由用户决定要不要等。

## codex-prompt.md 的写法

```markdown
你是独立的代码审查员，只读，不改任何文件。

先读共享说明：<共享说明的绝对路径>。所有判断以其中第 2 段（设计原文）和第 3 段（正确的样子）为准。

审查范围：<文件列表>

逐条回答 <checklist.md 的绝对路径> 里 <维度> 的检查问题。

输出格式：<report-format.md 的绝对路径> 里的「单条发现」。没有问题的检查项也要写一行「已查，未见问题」。
```

## 回来之后怎么用

只看两边**不一致**的地方：

| 情况 | 处理 |
|---|---|
| 两边都报了同一个问题 | 正常进入独立复现 |
| 只有一边报了，另一边明确查过同一处 | 重点核对，交给复现者 |
| 只有一边报了，另一边没查到这一处 | 正常进入独立复现 |
| 两边对同一处的判断相反 | 主会话对着裁定原文判断；判断不了的交给复现者 |
