# 测试矩阵

执行流程第 0 步按改动类型选测试，第 1 步建基线，第 3 步逐项验证。一条改动可能同时属于几类，取并集。

## 通用：每一类都要做

| 测试 | 做法 | 过闸条件 |
|---|---|---|
| 全量回归 | `bash scripts/ci.sh` | 全绿 |
| **撤回即失败** | 在 `git archive` 导出的副本或 scratch 副本里，把本次改动的关键部分撤回（或用 monkeypatch 改回旧行为），跑本条新写的测试 | 新测试必须变红；不变红说明测试守不住行为，重写测试 |
| 源码对照 | 测试工程师报告里每条结论带 `file:line`，主会话抽查 | 抽查的都对得上 |

## 按改动类型

### 行为不变的重构（W15、W16、W12 这类）

| 测试 | 做法 | 过闸条件 |
|---|---|---|
| 特征测试 | 改动前把要动的模块现有行为写成测试（输入 → 输出快照） | 在旧代码上全过 |
| **A/B 对照** | 同一份固定数据集（造数数据集或其中切片），**确定性替身模型**，旧代码（A）和新代码（B）各跑一遍真实整条链，比对全部落盘产物 | 逐字节一致；有差异逐条解释并对上设计，解释不了算失败 |
| 覆盖率 | 对比 A、B 的覆盖率报告 | 不下降 |
| 闸的基线 | 尺寸闸、类型检查闸 | 基线条数只减不增 |
| **对抗测试**（W16 必做） | 往每类边界注入坏数据：磁盘文件（截断、错类型、多字段、重复键）、HTTP 入参、插件载荷、模型输出、配置 YAML | 全部仍被拒收，报错信息和改动前同样明确 |

### 平台适配（W1、W2、W18 这类）

| 测试 | 做法 | 过闸条件 |
|---|---|---|
| 三平台 CI | macOS、Linux、Windows 各跑 `scripts/ci.sh` | 全绿，不跳过平台相关用例 |
| **对抗测试** | 写到一半杀进程后重启；两个实例抢同一把锁；替换文件时文件正被占用；只差大小写的文件名；保留名（CON、NUL…）；超长路径；用户名含中文或空格；只读目录；在会解密 TLS 的代理后面（自签 CA 模拟） | 每项有测试或实测记录；不丢数据、不卡死、报错可读 |
| **真实宿主实测** | 六个宿主逐个：装插件、记忆召回、会话送达、提醒出口 | 每个宿主每项都有实测记录（截图或日志） |
| 无管理员 | 普通用户账户从零安装 | 全程没有提权 |

### 新适配器或新后端（W7、W8、W10a 这类）

| 测试 | 做法 | 过闸条件 |
|---|---|---|
| 契约测试 | 和现有实现跑同一套参数化契约测试 | 全过 |
| **A/B 对照** | 同一数据集，旧实现和新实现的结果对比（向量库：召回前 k 条重合度；适配器：同一请求的结构化结果） | 差异在预先写死的范围内 |
| 重启读回 | 写入、关闭、重新打开、读回 | 一致 |
| **对抗测试** | 维度不符、容量超限、文件损坏、并发写、服务返回异常结构 | 明确失败或可重试，不静默写坏 |
| **真实模型提示词对照**（换模型或换协议时必做） | 同一批输入，旧模型和新模型各跑每份受影响的提示词，逐条比结果 | 结果对上设计；不合格的按"判法不写错例清单"改提示词后重跑 |

### 修 bug

| 测试 | 做法 | 过闸条件 |
|---|---|---|
| 复现用例 | 第 1 步在旧代码上写出会失败的用例 | 旧代码上失败 |
| 修复前后各复现一次 | 旧代码副本和新代码各跑一次 | 前失败、后通过，结果记进问题总清单 |
| 影响面 | `fix` 模式的 checklist F 组 | 全部回答 |

### 配置或默认值变更（W3、W11 这类）

| 测试 | 做法 | 过闸条件 |
|---|---|---|
| 配置矩阵 | 配置加载测试覆盖新字段、新默认值、非法值 | 全过 |
| 交互分支 | init 的每个分支（例如时区"检测到 / 检测不到"） | 全过 |
| **A/B 对照** | 受默认值影响的产物逐条对比（例如时区改了以后 Event 落在哪一天） | 每条差异都是预期内的 |

### 文档（W6、W14 这类）

| 测试 | 做法 | 过闸条件 |
|---|---|---|
| 逐句对源码 | 每一句描述行为的话，写出对应的 `file:line` | 全部对得上 |
| 引用完整 | 架构测试：代码里的"裁定 N"在 `docs/rulings/` 都有条目 | 全过 |

## 固定数据集

- 全链路 A/B 用造数数据集（`~/Desktop/habitus数据集/`），按特征挑切片，不按位置截前 N 条。
- 结构性改动用确定性替身模型（可复现、不花钱）；只有提示词或模型变更才用真实模型。
- A 侧产物在改动前生成并存档；B 侧在同一输入、同一配置下生成。
